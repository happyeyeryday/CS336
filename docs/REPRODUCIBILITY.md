## 小规模数值记录

随机种子均为 2025，参数和数据尺寸见各 `examples/smoke.py`。

- 作业一的 5 步 loss：`4.136675 → 3.890237 → 3.650775 → 3.419900 → 3.198703`。仅用于确认微型训练正常，不是语言模型质量指标。
- DDP 更新后参数最大绝对误差：逐参数版本 `2.98e-8`，分桶/累积版本 `0`。
- TP 最大输出误差 `7.15e-7`，最大梯度误差 `7.75e-6`。
- PP 最大输出误差 `1.12e-8`，最大梯度误差 `9.92e-5`，使用原实现的 `×1000` 损失缩放。

不同 CPU/BLAS 版本可能产生浮点差异，验收采用脚本中的容差，不要求逐字复制这里的误差值。CUDA 验证需要重新记录设备、版本和结果。

## 自动检查与更新

[GitHub Actions](https://github.com/happyeyeryday/CS336/actions) 在 push/PR 时执行仓库检查、作业一 CPU smoke 和作业三三种 CPU 模式；绿色状态仅覆盖这些检查，不包含 GPU 或未完成的官方作业测试。

仓库检查命令为 `python scripts/check_repository.py`，需要 Python 3.11+ 和完整 Git checkout。它检查语法、声明文件、中文说明中的本地链接、发布体积、必要 fixtures 和当前未实现接口数量。

新增复现结果时，请保留运行命令、commit、软件/硬件版本及随机种子，区分“小样例正确性”“完整训练”“性能测量”。运行产物保存在忽略的 `outputs/` 下，不随源码提交。
